# 术语表

| 锚点 | 定义 | 别名 |
|---|---|---|
| strict-json | 直接审查角色的完整最终回复可解析为唯一 JSON 对象，且对象前后没有说明文字、围栏或其他内容 | 严格 JSON |
| review-snapshot | 提交前审查启动时记录的分支头与内容指纹，用于核对审查结果对应的正是待推送的内容 | 审查快照 |
| material-decision | 存在合理替代方案、已选定其一准备执行，且该选择会改变行为、范围、授权、架构、风险、恢复路径或流程分支的选择 | 材料性决定 |
| decision-ledger | 跟随单个需求保存、分别记录该需求 AI 决定与用户决定的追加式记录文件，一项已形成决定恰好占一行 | 决策台账 |
