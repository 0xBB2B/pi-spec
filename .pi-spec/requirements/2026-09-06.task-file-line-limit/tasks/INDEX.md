## 被否定的备选方案

- 一个任务修改三份公开指令：超过每任务最多 2 个生产文件的既定限制。
- 按三条验收拆成依赖链：会重复触碰同一生产文件，且没有真实编译或数据依赖。

## 根源性自检与采用理由

- 根源是三个入口的计数对象与豁免口径冲突；两任务覆盖所有入口及完整验收，不靠新增计数工具缓解症状。
